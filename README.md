# Mood Tracker 📝😊

Aplicación para registrar estados de ánimo con emociones jerárquicas, sin backend, solo almacenamiento local. Desarrollada con React + TypeScript.

## Funcionalidades

- ✍️ Crear entradas con texto, fecha y emociones jerárquicas (árbol de sentimientos).
- 🌳 Selección de emociones con límites configurables (raíces, hijos por nodo).
- 📋 Visualización en feed ordenado por fecha descendente.
- ✏️ Editar entradas existentes.
- 🗑️ Eliminar entradas con confirmación.
- 💾 Persistencia en `localStorage`.
- 🎨 Interfaz simple con estilos inline (fácil de customizar).

## Tecnologías

- React 19
- TypeScript
- React Router 7
- Vite
